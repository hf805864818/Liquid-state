Liquid-state 总开关默认值修改报告

项目: hf805864818/Liquid-state | 修改日期: 2026-09-15

修改文件: 5 改动行数: +43 / -9

已将用户指定的 13 个功能总开关的默认值从「开启(YES)」修改为「关闭(NO)」，涵盖深色模式和浅色模式。

修改涉及三个层面：运行时核心检查、设置界面 UI 默认值、Hook 互斥逻辑回退值。

一、修改前的默认值分析

项目中功能总开关的默认值由以下三层机制共同决定：

1. 运行时核心检查 — lgHostEnabled()

位于 Shared/LGGlassKit.x，是所有 Hook 文件调用的核心函数。当用户未设置偏好值时，原逻辑仅对 AppIcons 返回 NO，其余全部返回 YES（默认开启）。

2. 设置界面 UI 默认值 — LGRendererItemsForHostPrefix()

位于 LiquidAssPrefs/LGPrefsDataSupport.m，控制设置面板中开关的初始显示状态。原逻辑 enabledByDefault = ![prefix isEqualToString:@"AppIcons"]，即除应用图标外全部默认开启。

3. Hook 互斥逻辑回退值

灵动岛 DI1/DI2 互斥逻辑中，LG_prefBool(@"DynamicIsland.Enabled", YES) 使用 YES 作为回退值，导致未设置时 DI1 被视为开启状态，会阻止 DI2 工作。

三、具体修改详情

Shared/LGGlassKit.x — lgHostEnabled() 运行时核心默认值

将默认返回值从仅排除 AppIcons，扩展为排除全部 13 个指定功能的 prefix。使用 dispatch_once + NSSet 保证线程安全与高效查找。

- if ([prefix isEqualToString:@"AppIcons"]) return NO; - return YES; + static NSSet *disabledByDefaultPrefixes; + // ... dispatch_once 初始化 NSSet ... + if ([disabledByDefaultPrefixes containsObject:prefix]) return NO; + return YES;

// 这是所有 Hook 调用的核心检查函数。未设置偏好时返回 NO = 功能关闭。

// 深浅模式均生效：LGGlassPreferenceValue() 先查 .Light/.Dark 后缀键，无值时回退到基础键，最终由此函数决定默认值。

LiquidAssPrefs/LGPrefsDataSupport.m — LGRendererItemsForHostPrefix() UI 默认值

设置界面中开关的初始显示状态。修改后，所有指定功能在设置面板中默认显示为关闭。

- BOOL enabledByDefault = ![prefix isEqualToString:@"AppIcons"]; + BOOL enabledByDefault = !([prefix isEqualToString:@"AppIcons"] || + [prefix isEqualToString:@"FolderIcon"] || ... || + [prefix isEqualToString:@"Keyboard"]);
LiquidAssPrefs/LGPrefsDataSupport.m — LGKeyboardItems() 键盘受控面板

键盘几何参数（圆角、突出度）面板的 enabled_default 从 @YES 改为 @NO。

- ], @"Keyboard.Enabled", @YES), + ], @"Keyboard.Enabled", @NO),
Hooks/DynamicIsland.x + Hooks/DynamicIsland2.x + Shared/LGDI2Mutex.h — 灵动岛互斥逻辑

共 5 处 LG_prefBool(@"DynamicIsland.Enabled", YES) 改为 NO，确保 DI1 未设置时不会被误判为开启状态，从而不会错误阻止 DI2 工作。

四、深浅模式生效说明

深浅模式分离机制：当 Appearance.SeparateModes 开启时，LGGlassPreferenceValue() 会优先查找带 .Light 或 .Dark 后缀的偏好键。如果模式特定键不存在，回退到基础键；如果基础键也不存在，则由 lgHostEnabled() 的返回值决定。

本次修改将 lgHostEnabled() 的默认返回值改为 NO，因此无论深色还是浅色模式，只要用户未显式设置偏好值，功能均处于关闭状态。
