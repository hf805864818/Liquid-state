# 0.1.14b

## Bug 修复

- 修复滑块震动强度过弱的问题（震动强度由轻触感提升至中等触感，intensity 调整为 0.6）
- 修复 GitHub Release 版本号冲突导致发布失败的问题（版本号从 0.1.13b 升至 0.1.14b）

## 性能优化

- **控制中心自定义背景发热优化 A：静态图片预渲染模糊** — 不再使用 `UIVisualEffectView` 实时模糊，改为预渲染模糊图片，大幅降低 GPU 负载
- **控制中心自定义背景发热优化 B：视频帧率限制 30fps** — 背景视频从默认 60fps 降至 30fps，降低解码和渲染功耗，视觉无明显差异
- **控制中心自定义背景发热优化 C：模块级视频图层智能隐藏** — 控制中心不可见时隐藏所有模块视频图层，避免后台持续渲染
- **控制中心自定义背景发热优化 D：layoutSubviews 节流** — 尺寸未变化时跳过重复布局和媒体加载，减少 CPU 占用

## 其他改进

- 添加 CoreImage 框架依赖以解决编译警告
- 修复 ARC 模式下 `performSelector` 泄漏警告
