# 0.1.288b

## 修复
- 收缩灵动岛时遗留"大灵动岛玻璃阴影"无法消失：展开玻璃拆除（`LGDIDestroyExpandedGlass`）时同步清掉 `glass.layer.mask`（高光 mask 含黑描边/渐变），避免 render server 残留大岛玻璃视觉。
- 活动（展开）时灵动岛周边闪烁黑边框 + 收缩遗留玻璃毛边：玻璃高光 mask 的 `borderWidth = 0.75` 黑描边是两问题的共同根因——该描边在 render server 重采样 / 展开玻璃拆除时被重绘/残留出来。置 0 去掉黑描边，玻璃主体（折射 / 模糊 / 高光渐变）完全保留。

## 说明
- 两处改动同根因：`LGLiveBackdropView.m` 高光 mask 的 0.75pt 黑描边 + 展开玻璃拆除未清 mask。
- 基于 0.1.284b（5cfaa74）最新代码修改，保留 0.1.284b 已有的 reparenting / 竞态修复。
