# 0.1.8b

## 重命名

- 插件名称更改为「Ai液态玻璃」
- 底部注销按钮名称从「重启 SpringBoard」改为「注销」

## 新功能

- 按应用排除玻璃效果：可在指定应用中完全禁用玻璃效果
- 深/浅色模式独立参数：可为浅色和深色模式分别配置玻璃效果参数
- 竖屏音量HUD玻璃效果：为竖屏状态下的音量HUD添加玻璃效果
- 控制中心快速开关：可从控制中心快速开启或关闭玻璃效果
- 自定义控制中心背景：支持图片/视频背景及模糊度调节
- 预设主题：提供均衡、轻盈、深邃、磨砂、水晶、霓虹、宣纸、极光等8种预设风格
- 表面自定义排序：支持默认、字母顺序、自定义拖拽排序
- 导入/导出偏好设置：支持 JSON 格式配置分享与恢复
- 复制调试信息：一键复制设备和设置信息到剪贴板

## 控制中心滑块增强

- 百分比显示：在音量和亮度滑块上方显示当前百分比值
- 圆角调节：可自定义滑块填充的圆角大小
- 液态玻璃效果：为控制中心音量和亮度滑块添加液态玻璃效果

## Bug 修复

- 修复时钟字体选择器点击无反应的问题（iOS 15+ 配置重置导致菜单失效）
- 修复字重预设显示英文的问题（现已中文化）
- 修复控制中心背景设置点击无反应的问题（改为直接加载偏好设置包）
- 修复关于页面图标过大的问题（从82pt缩小为60pt）
- 修复设置入口图标分辨率过高的问题（调整为标准 iOS 偏好设置图标尺寸）

## 性能优化

- 动态质量：滚动和动画时自动降低玻璃质量以保持流畅帧率
- 内存节省模式：降低纹理分辨率和渲染复杂度以减少内存占用
- 低电量模式优化：低电量下自动降低渲染质量
- 专注模式优化：专注模式下自动调整玻璃质量
- 自适应模糊：根据屏幕亮度自动调整模糊强度
- 壁纸颜色染色：从壁纸中提取颜色为玻璃表面染色

## 其他改进

- 横幅动画：平滑玻璃淡入和弹性效果
- 滑块振动反馈：控制中心滑块触觉反馈
- 运动高光：利用设备运动引导玻璃镜面高光
- iOS 26 时钟字体支持
- 自定义日期格式
- 去除捐赠功能
- 默认语言设为简体中文
