# 0.1.153b

## Bug 修复

- **修复磨砂模式时钟的矩形模糊区域** — 0.1.152b 修复了 shader 层面的液态效果溢出，但 `_nativeBlurLayer`（CABackdropLayer）仍然产生可见的矩形模糊区域
  - **根因**：CABackdropLayer 的 `ignoresScreenClip=YES` 导致父层 mask 无法裁剪 backdrop 捕获区域，高斯模糊在整个 overlay bounds 内可见
  - **修复**：Clock 不再创建独立的 `_nativeBlurLayer`，改为将高斯模糊作为 CAFilter 直接添加到主 backdrop layer 的 filters 数组中（`@[gaussianFilter, glassFilter]`）
  - **原理**：高斯模糊 filter 先处理 backdrop，然后液态玻璃 shader 采样已模糊的 backdrop，并通过 mask 纹理裁剪到文字形状内，彻底消除矩形模糊区域
