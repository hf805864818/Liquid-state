# 0.1.152b

## Bug 修复

- **修复时钟显示区域周边阴影/矩形边框问题** — 影响所有磨砂模式预设，iOS 26 扁平和磨砂粗黑尤为明显
  - **Shader 修复**：glyph mask 模式下增加当前像素 mask 采样，文字外像素直接返回原始背景，不再输出液态效果（着色、折射、菲涅尔、高光）
  - **edgeOpacity 平滑过渡**：从硬编码 1.0 改为 smoothstep，文字边缘抗锯齿像素自然过渡
  - **禁用 Clock specular 高光**：防止 0.75pt 白色矩形边框出现在 overlay bounds 周围
  - **Native blur 形状裁剪**：磨砂模式的高斯模糊层添加文字形状 mask，消除矩形模糊区域
