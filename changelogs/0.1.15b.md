# 0.1.15b

## 性能优化

- **CoreMotion 传感器降频** — 运动高光更新频率从 10Hz 降至 5Hz，传感器功耗降低约 50%；无可见玻璃时直接跳过计算，进一步降低空闲功耗
- **LGLiveBackdropView layout 节流** — 尺寸和圆角未变化时跳过 `applyFilters` 和 `updateSpecular`，避免滚动/动画场景下重复渲染
- **MTMaterialView 路由快速路径** — 已注入玻璃的视图直接同步几何，跳过所有 host route 匹配，减少 layout 时的 CPU 开销
- **Preferences DisplayLink 降帧** — 设置界面分段控制从最高 120fps 降至 30fps，设置交互不需要 ProMotion
- **CoverSheet DisplayLink 降帧** — 封面页几何同步从默认帧率降至 30fps，位置同步不需要高帧率
- **TabBar DisplayLink 降帧** — 底栏透镜动画从默认 60/120fps 限制为 60fps，ProMotion 设备上省电且仍流畅

以上所有优化均不影响视觉效果和基本功能
