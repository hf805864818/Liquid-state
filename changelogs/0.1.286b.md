# 0.1.286b

## 活动开始黑边闪烁 2-3 次 根因修复

### 问题
灵动岛实时活动**刚启动时**黑框闪烁 2-3 次，稳定后不再闪。
根因（逐行代码 + 项目自身提交记录交叉验证）：

1. **主因 — host 切换滤镜销毁循环**
   Spring 展开/收缩动画中系统重排 curtain 祖先链 → `LGDIHostForCurtain`
   返回新 host → `LGDIDoScheduledSync` 走 `removeFromSuperview` 重装路径。
   每次重装触发 `LGLiveBackdropView.didMoveToWindow(nil)` → `layer.filters=@[]`
   （render server 销毁捕获组，1-2 帧无滤镜）+ `didMoveToWindow(win)` →
   `applyFilters`（重建滤镜，首帧采样未就绪）。
   弹簧弹跳 2-3 次 = 2-3 次重装 = 闪烁 2-3 次，与症状精确对应。
   独立 DisplayLink（a43faf8）只保护 driver 稳态，不保护活动启动阶段。

2. **辅因 — 展开玻璃首帧滤镜未真正挂上**
   `LGDIEnsureExpandedGlass` 创建玻璃时 `init` 内 `applyFilters` 可能 early
   return（捕获组未 ready），真正挂滤镜依赖 0.2s 延迟 `lgForceRefreshBackdrop`，
   中间 0.2s 窗口展开卡片无液态玻璃 = 黑底透出。

3. **堆积 — 延迟刷新回调堆积**
   锁定期（driver 刚启动）内多个延迟回调各自 0.2s 递归重试，锁定期结束瞬间
   同时命中"未锁定"分支 → 多次重采样 → 黑边闪。

### 修复

| 编号 | 改动 | 文件 |
|------|------|------|
| P0-1 | 新增 `lgSetReparenting:` 标记；`didMoveToWindow(nil)` 命中 reparenting 时跳过 `layer.filters=@[]` 清空，保留捕获组不销毁 | LGLiveBackdropView.{h,m} + DynamicIsland.x |
| P0-2 | pill 玻璃 host 切换重装前 `[sLGDIGlass lgSetReparenting:YES]`；展开玻璃 host 切换前同样标记 | DynamicIsland.x (LGDIDoScheduledSync / LGDIEnsureExpandedGlass) |
| P0-3 | 展开玻璃创建后立即检查 `layer.filters.count`，为 0 则同步 `applyFilters`，消除 0.2s 滤镜未挂窗口 | DynamicIsland.x (LGDIEnsureExpandedGlass) |
| P1 | `LGDIDelayedRefreshBackdrop` 锁定期内不再递归重试，改全局 `sLGDIDelayedRefreshPending` 标记，锁定期结束后由下一个非锁定回调统一触发一次（消除 3-4 个回调堆积） | DynamicIsland.x |
| P2 | host 切换重装后立即同步 `LGDISweepView` + `LGDIStripNearBlackSubtree`（不等 dispatch_async），防新 container 近黑背景透出 1-2 帧 | DynamicIsland.x |

### 不采用的修复（查证后判定为死代码）
- CAFilter 未注册 pending 重试：`registerCustomFilter` 在 backboardd 进程启动
  （`__attribute__((constructor))`）时完成注册并广播 `kLGParametersReloadedNote`，
  远早于任何活动启动。活动启动时 filter table 必然就绪，该路径不会命中。
  引入跨进程时序依赖风险大于收益，跳过。

### 行为说明
- 拆除路径（`LGDITeardown` / `LGDIDestroyExpandedGlass`）的 `removeFromSuperview`
  仍走原清空逻辑（非 reparenting），正确——真正离屏时省电是必要的。
- `_lgReparenting` 在 `didMoveToWindow` 两个分支（nil/win）都会复位为 NO，
  不会残留。
- 重新挂载时 `applyFilters` 走 early-return（`_filterAttached` 仍 YES 且
  `layer.filters.count==1` 且基类型相同），不重建捕获组，黑边消除。
